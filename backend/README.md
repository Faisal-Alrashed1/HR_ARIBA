# backend
الخادم (قيد البناء). كل الحسابات والصلاحيات هنا وليس في المتصفح.
- `app/core/` الدخول، الصلاحيات، الأمان
- `app/routers/` واجهات API لكل قسم
- `app/services/` المعادلات — المرجع: docs/ARIBA_HR_System_Documentation.md القسم 4، والكود في legacy/*/js/calculations
- `app/models/` جداول قاعدة البيانات
- `tests/` اختبارات، ومنها مقارنة النتائج بأمثلة التوثيق
